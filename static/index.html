Preferred: .xlsx · Also supported: .xls · .csv

Expected columns (any order, header row required):
Item Description *, Part Number, Serial Number, Rank, Speed, Capacity, Category, Location, Team, Owner, Check Out User, Check Out Email, Check Out Date, Loan Until, Notes.
Check Out Email is optional on a new row, but a loan imported without one cannot be sent a reminder or a return request — Reports lists them.
Multiple sheets supported — sheet name used as category fallback.

One file does everything. A row with a blank Action adds a new item. Put check_out, check_in or change_user in the Action column to act on an item already in the inventory — change_user reassigns a loan without checking it in first. Those rows are matched by Serial Number, then Part Number, and must carry a Check Out Email when they name a borrower. Location and Tray / Comment are optional on an Action row: fill them in to move the item at the same time, leave them blank to keep what is stored.
Returning a batch? Filter the inventory, export it, type check_in down the Action column and upload that file here — an export carries the same columns.
